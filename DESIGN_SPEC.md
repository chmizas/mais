# Design Specifications - M.Sc. Information Systems (MAIS DUTH)

## Objective
Modernize the existing academic website (mais.mst.duth.gr) into a responsive, highly professional, fast, and accessible web application using clean HTML5, Tailwind CSS, and vanilla JavaScript.

## Visual Identity & Theme
- **Style:** Modern Academic & Tech-focused, clean layout with ample whitespace, high contrast, and smooth interactions.
- **Color Palette (DUTH Academic + Modern Tech):**
  - **Primary Brand (DUTH Crimson):** `#8B1538` or `#9E1B32` (Used for Logos, Primary Buttons, Active States)
  - **Tech Navy (Dark Backgrounds/Titles):** `#0F172A` (Rich dark slate/navy for modern tech feel)
  - **Neutral Light Background:** `#F8FAFC`
  - **Card/Section Background:** `#FFFFFF` or `#F1F5F9`
  - **Accent / Alert (Vibrant Red):** `#E11D48` (Used for "New Announcement" badges, highlights)
  - **Body Text:** `#334155` (Slate gray for comfortable reading)

## Key Architecture & Components
1. **Header / Navigation:**
   - Sticky navbar featuring the Red/White DUTH & MAIS branding.
   - Clean navigation links: Home, Program Structure (Μαθήματα), Admission (Αιτήσεις), Services (Υπηρεσίες), Contact.
   - Prominent Call-To-Action (CTA) button with DUTH Crimson background: "Αίτηση Συμμετοχής".

2. **Hero Section:**
   - Dark Tech Navy (`#0F172A`) background with subtle modern tech patterns/gradients.
   - Bold title: "ΠΜΣ Πληροφοριακά Συστήματα"
   - Subtitle highlighting distance learning (Εξ Αποστάσεως) and career growth.
   - Action buttons: "Προκήρυξη" & "Πρόγραμμα Σπουδών".

3. **Feature Cards (Grid Layout):**
   - Interactive cards with crimson/navy icons highlighting key benefits (100% Online, Applied IT Skills, Career Boost).

4. **Interactive Lead Form (Εκδήλωση Ενδιαφέροντος):**
   - Clean form with input validation for prospective students.

5. **Footer:**
   - Dark Navy footer containing official institutional links (DUTH, E-learning, Library) and contact details.
